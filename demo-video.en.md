# Terraform Live Values & Results — VS Code walkthrough

## Walkthrough

This video progresses from the simplest examples to more complex Terraform configurations. We start with variable values and basic functions in locals, then move on to Azure resource configurations, module calls and their outputs.

The walkthrough covers `for` with an `if` filter, `flatten`, `merge`, `concat`, `distinct`, `zipmap` and grouped results. It then shows a `for_each` collection, a complete resource, and individual `each.value` and `each.key` references for a selected instance. Examples include NSGs, route tables, subnet delegation, `count`, all input variables and the final result of the network module.

This is a recording of Live Values & Results for Terraform 0.0.11 running in VS Code on Linux with a synthetic configuration. Circles mark clicks and an outline highlights the result panel. The preview calculates values locally; the recording does not run `terraform plan` or `apply`. Provider-dependent fields remain unresolved or appear as reference addresses.

The interface and captions are in English. There is no voice-over. A separate Polish version is also available.
